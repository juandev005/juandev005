## 🚀 ¿Qué hago?

- **QA Automation**: Diseño y mantengo frameworks E2E con Playwright y Selenium bajo el patrón Page Object Model, cubriendo flujos críticos del producto.
- **Performance Testing**: Pruebas de carga y estrés con k6, métricas visualizadas en dashboards de Grafana para identificar cuellos de botella.
- **Security Testing**: Análisis de vulnerabilidades OWASP Top 10 sobre APIs y flujos de autenticación con OWASP ZAP y Burp Suite.
- **API Testing**: Validación de REST APIs con Postman y REST Assured; análisis de payloads, headers y red con DevTools.
- **CI/CD Integration**: Integración de suites de prueba en pipelines con GitHub Actions y Jenkins para feedback continuo.
- **Data & Observabilidad**: Reportes de cobertura y métricas de calidad con Pandas/Matplotlib, trazabilidad de errores con Logfire.
